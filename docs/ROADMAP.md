# KaigiAI — дорожная карта

> **Статус:** порядок этапов утверждён 2026-10-13: v0.1.4 → v0.2 → v0.3 (LAN) →
> v0.4 (установка) → v0.5 (macOS) → v1.0. Открытые вопросы — в конце. Реализованное
> до v0.1.3 описано в [PROJECT.md](PROJECT.md) §11.

## Ветки и релизы

- Вся разработка — в ветке **`dev`**.
- В **`main`** попадают только готовые версии: merge `dev → main` (`--no-ff`,
  «release vX.Y.Z») + тег `vX.Y.Z`. История `main` = список релизов.
- Изменения по версиям — в [CHANGELOG.md](../CHANGELOG.md).

## Откуда взялись приоритеты

Внешний обзор проекта (статья «Субтитры-перевод на созвоне: KaigiAI без переводчика»,
chimitdorzhi.tech, 2026-10-04) посмотрел на KaigiAI глазами компании, которая хочет
его внедрить. Его претензии почти все справедливы и сводятся к трём темам:

1. **Доверие** — нет файла лицензии, exe без подписи (SmartScreen), один автор, v0.1.
2. **Измеримость** — нет цифр задержки по железу, качество на китайском/корейском/
   монгольском не проверено, неясно, как система ведёт себя при 4–5 языках.
3. **Сценарий «участники встречи»** — перевод видят только на экране ведущего;
   нет раздачи на устройства участников по локальной сети.

Отсюда порядок: сначала дёшево закрыть доверие, затем сделать продукт измеримым и
быстрее на N языках, затем расширять сценарии.

## v0.2 — Измеримость и скорость на N языках

- **Метрики задержки по стадиям.** Для каждой реплики: конец речи (VAD) → STT →
  каждый перевод → показ. Хранить в БД/логе, показывать в отладочной панели
  (скрыта по умолчанию).
- **Бенчмарк-набор.** Фиксированные аудиозаписи (ru/en/ja/zh/ko/id, 2 и 4 языка) +
  скрипт, который прогоняет их через пайплайн и выдаёт таблицу задержки и
  (по эталонным переводам) грубую оценку качества. Опубликовать таблицу
  «железо × модели × число языков» в README.
- **Перевод в N языков быстрее.** Сейчас каждая цель — отдельный LLM-вызов. Варианты:
  (a) параллельные запросы к llama-server (`--parallel N`, общий KV-кеш);
  (b) один вызов с JSON-ответом «все языки сразу». Выбрать по бенчмарку.
- **Глоссарий терминов.** Глобальный + на беседу: имена, артикулы, названия
  компаний. Подмешивается в промпт перевода и в `initial prompt` Whisper (улучшает
  распознавание имён). Это прямой запрос из B2B-сценария (Китай/Корея).
- **Проверка CJK и редких языков** на бенчмарке; честная пометка в UI
  «качество не проверено» для непротестированных пар.

## v0.3 — Перевод на устройствах участников (LAN)

- Встроенный HTTP/WS-сервер (Axum — тот же, что задуман для self-host, §14) отдаёт
  read-only страницу-презентер.
- Ведущий показывает **QR-код**; участник открывает его на телефоне/ноутбуке и
  **сам выбирает язык**. Нет лимита «два окна».
- Безопасность: случайный токен в URL на сессию, только локальная сеть, явный
  индикатор «трансляция включена», остановка одной кнопкой.
- Побочный эффект: первый реальный кусок серверного режима из §14.

## v0.4 — Установка в один клик

- **Встроенный менеджер моделей**: скачивание серверов и весов прямо из приложения
  (с прогрессом, докачкой, проверкой SHA-256), вместо ручных ссылок в мастере.
- **Автоопределение железа** (VRAM/CUDA) → предложение тира Low/Mid/High (§10.1).
- Опционально — инсталлятор с выбором «CPU / CUDA» вместо одного portable exe.

## v0.5 — macOS (Apple Silicon)

  ScreenCaptureKit (аналог WASAPI loopback).

## v1.0 — Self-host и стабильность

- Аутентификация для многопользовательского сервера.
