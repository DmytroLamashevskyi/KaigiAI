# Тестирование KaigiAI

Практический чек-лист для ручной проверки. Главный фокус сейчас —
**N-язычный режим (3+ языка), §10.7** и его доработки. Технический дизайн —
в [PROJECT.md](PROJECT.md) §10.7.

## Перед началом

- **Сборка:** `portable/KaigiAI.exe` (один файл, ничего ставить не нужно) или
  `npm run tauri dev` для дев-режима.
- **Где данные** (для отладки/сброса):
  - БД: `%APPDATA%\ai.kaigi.desktop\kaigi.db`
    (`C:\Users\<вы>\AppData\Roaming\ai.kaigi.desktop\kaigi.db`).
  - Логи: `%LOCALAPPDATA%\ai.kaigi.desktop\logs\kaigi.log`.
  - Аудио-клипы (если включено «сохранять запись»): `…\Roaming\ai.kaigi.desktop\audio\`.
- **Режим перевода:** для быстрой проверки логики удобнее API-режим (мгновенные
  ответы). Локальный режим (whisper.cpp + llama.cpp) проверяет реальную задержку и
  качество — см. [README](../README.md).
- **Сброс состояния:** закрыть приложение и удалить `kaigi.db` — следующий запуск
  начнётся с чистого листа.

## 1. Базовый 2-язычный режим (регресс)

Сначала убеждаемся, что привычный путь не сломан.

- [ ] **Новый диалог** → в шапке два селектора языка (например, Русский / 日本語) и
      кнопка ⇄ (своп). Это классический 2-колоночный вид.
- [ ] Печатаем текст на русском → попадает в левую колонку, перевод — в правую.
- [ ] Печатаем текст на японском → попадает в правую колонку, перевод — в левую
      (детекция по алфавиту).
- [ ] ⇄ на строке (появляется при наведении) переносит реплику на другую сторону и
      переводит заново.
- [ ] Запись с микрофона: речь распознаётся, переводится, появляется в нужной колонке.

---

## 2. Переход в N-язычный режим (добавление языка)

- [ ] В шапке 2-колоночного вида есть кнопка **«＋ язык»** (между колонками).
      Нажать → выбрать третий язык (например, English).
- [ ] Вид сразу превращается в **сетку из 3 колонок** (Русский / 日本語 / English).
- [ ] **Старые** реплики (созданные до добавления) показывают **«—»** в новой
      колонке (English) — историю мы намеренно не до-переводим.
- [ ] У каждой колонки в шапке есть «×» для удаления языка; под шапкой —
      «＋ язык…» и кнопки презентеров «⤢ 1 / ⤢ 2».

> Важно: «—» = перевода нет. Пока перевод идёт, показывается «…» (см. сценарий 4).

---

## 3. N-язычный ввод текста

В беседе из 3+ языков:

- [ ] Печатаем фразу на русском → оригинал в колонке «Русский» (выделена рамкой),
      переводы появляются в 日本語 и English.
- [ ] Печатаем фразу на японском → оригинал в 日本語, переводы в Русский и English.
- [ ] Печатаем фразу латиницей → оригинал в English.
- [ ] В каждом случае **все** остальные колонки заполняются переводом.

## 4. Индикатор «переводится…»

- [ ] Сразу после ввода/записи целевые ячейки кратко показывают **«…»** (идёт
      перевод), затем — текст. (В локальном режиме «…» видно несколько секунд, в
      API — почти мгновенно.)
- [ ] «…» не путать с «—»: «…» = переводится сейчас, «—» = перевода нет и не будет.

## 5. ⇄ Смена языка реплики (N языков)

- [ ] Навести на строку → справа от метаданных появляется **⇄**. Нажать → меню со
      списком других языков беседы.
- [ ] Выбрать язык (например, реплику ошибочно отнесло к Русскому, а она японская →
      выбрать 日本語). Оригинал **переезжает** в выбранную колонку, остальные
      колонки переводятся заново.

## 6. Чужой язык (вне набора)

- [ ] **Настройки → включить «Определять чужие языки»** (`detectForeignLanguages`).
- [ ] Произнести/ввести реплику на языке **вне** набора беседы (например, в беседе
      ru/ja/en — фраза на немецком).
- [ ] Оригинал показывается **во всю ширину** строки с бейджем языка, а ниже —
      переводы во все языки набора.
- [ ] При **выключенном** тумблере чужая речь принудительно относится к ближайшему
      языку набора (защита от ложной детекции whisper).

## 7. Окна-презентеры (второй экран)

- [ ] «⤢ 1» / «⤢ 2» открывают окна-презентеры. Каждое — **со своим выпадающим
      списком языка** (для 3+ языков). По умолчанию окно 1 = первый язык, окно 2 =
      второй.
- [ ] Сменить язык в выпадающем списке окна → содержимое перерисовывается на
      выбранный язык.
- [ ] Per-окно настройки (размер текста A−/A+, тема, «ориг.») запоминаются.
- [ ] Окна синхронизируются с главным в реальном времени (новые реплики приезжают).
- [ ] Окно закрывается крестиком (прячется и переоткрывается «⤢»), не плодит копии.
- [ ] **RTL:** добавить арабский (`ar`) в беседу → строки на арабском
      выравниваются справа налево и в сетке, и в презентере.

## 8. Удаление языка и предел

- [ ] «×» на колонке удаляет язык (минимум 2 остаётся). Колонка исчезает.
- [ ] Реплика, сказанная на удалённом языке, становится «чужой» карточкой (это
      ожидаемо). Переводы в БД сохраняются — **вернуть** язык через «＋ язык»
      восстановит их.
- [ ] Добавить языки до **5** → кнопка «＋ язык» сменяется подсказкой
      **«Максимум 5 языков»**.

## 9. Экспорт и персист

- [ ] **Экспорт** (меню диалога): Markdown / PDF / ZIP — содержат **все** языки
      беседы (по колонкам), а не только две.
- [ ] **Персист (проверка фикса гонки):** в N-язычной беседе ввести несколько
      реплик, дождаться переводов, **полностью закрыть и снова открыть** приложение
      → все переводы на месте (не пропали и не обнулились).
- [ ] AI-саммари и авто-заголовок (✨) работают как раньше.

---

## Известные ограничения (ожидаемо, не баг)

- Добавление языка переводит **только новые** реплики; история остаётся с «—» в
  новой колонке.
- Удаление языка не стирает уже сохранённые переводы (намеренно — для отката).
- Интерфейс пока полностью на русском (полная локализация UI — отдельная задача).
- N языков → до N−1 вызовов переводчика на реплику: в локальном режиме на 4–5
  языках задержка/нагрузка на GPU заметно растёт.

## Что приложить к багрепорту

Строку из `kaigi.log` на момент проблемы, шаги воспроизведения, и (если про
перевод/персист) — содержимое беседы из `kaigi.db` или скрин сетки.
