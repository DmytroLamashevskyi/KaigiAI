# KaigiAI — руководство пользователя

KaigiAI (会議AI) переводит **живую речь** между несколькими языками в реальном
времени. Говорите или печатайте — приложение распознаёт речь, определяет язык и
показывает перевод во все языки беседы. По умолчанию всё работает **офлайн**:
аудио и текст не покидают ваш компьютер.

Это руководство — для пользователя. Установка серверов/моделей и технические
детали — в [README](../README.md); чек-лист проверки — в [TESTING.md](TESTING.md).

---

## 1. Установка и первый запуск

1. Скачайте `KaigiAI.exe` (один файл, ставить ничего не нужно) и запустите.
2. При первом запуске Windows SmartScreen может предупредить о «неизвестном
   издателе» (приложение без цифровой подписи) — нажмите **«Подробнее» →
   «Выполнить в любом случае»**.
3. Откроется **мастер настройки**. Выберите сценарий работы:
   - **💻 Локально** — всё на вашем ПК (нужен GPU/CPU и разово скачанные модели,
     см. README). Максимальная приватность.
   - **☁️ API** — распознавание/перевод через облачный или локальный
     OpenAI-совместимый сервер (для слабых машин). Нужен адрес и ключ.
4. Мастер подскажет, чего не хватает (пути к серверам/моделям или API-ключ).
   Красные плашки-уведомления показывают, что настроено не так.

> Настройки можно открыть в любой момент внизу слева (⚙️ **Настройки**).

---

## 2. Основы: диалог на 2 языках

1. **＋ Новый диалог** (слева).
2. В шапке выберите два языка (например, **Русский** и **日本語**). Кнопка **⇄**
   меняет их местами. Языки можно менять, пока в диалоге нет реплик.
3. Нажмите **● Запись** и говорите — реплики появляются двумя колонками:
   оригинал слева, перевод справа (или наоборот — зависит от языка речи).
4. Или напечатайте текст в поле внизу и нажмите Enter — язык определяется
   автоматически по алфавиту, текст попадает в нужную колонку и переводится.
5. Наведите на реплику — появится **⇄**: перенести реплику на другую сторону,
   если язык определился неверно.

Как работает пауза: когда вы замолкаете, снизу появляется полоска отсчёта. Если
продолжить говорить — реплика не обрывается; если пауза выдержана — реплика
финализируется и переводится (короткое мерцание «обработка»).

---

## 3. Несколько языков (3–5)

1. В шапке диалога нажмите **«＋ язык»** и выберите третий язык.
2. Вид превратится в **сетку из N колонок** — каждая реплика показывается во всех
   языках беседы сразу. Колонка того языка, на котором реально сказали, выделена.
3. Управление языками:
   - **«＋ язык…»** под шапкой — добавить (до **5** языков; дальше появится
     подсказка «Максимум 5 языков»).
   - **«×»** на колонке — убрать язык (минимум 2).
   - **⇄** на строке (при наведении) — указать, на каком языке реально сказали
     реплику; перевод пересчитается во все остальные языки.
4. Индикаторы в ячейке:
   - **«…»** — перевод сейчас выполняется;
   - **«—»** — перевода нет. Так помечаются старые реплики после добавления
     нового языка: **историю приложение не до-переводит**, переводятся только
     новые реплики.

> Убрали язык и вернули обратно — сохранённые переводы восстановятся.

**Чужой язык.** Если кто-то заговорил на языке **вне** набора беседы, включите в
настройках **«Определять чужие языки»**: оригинал покажется во всю ширину с
бейджем языка, а ниже — переводы во все языки набора. Если тумблер выключен, речь
принудительно относится к ближайшему языку беседы (защита от ошибок распознавания).

## 4. Показ на второй экран (презентация)

Кнопки **⤢** открывают окна-презентеры для аудитории/проектора:

- Каждое окно показывает беседу крупно и **само выбирает язык** из выпадающего
  списка (для 3+ языков).
- В окне есть: размер текста **A− / A+**, тема (🌙/☀), тумблер **«ориг.»**
  (показывать исходную реплику под переводом). Эти настройки запоминаются на окно.
- Окна синхронизируются с главным в реальном времени. Закрываются крестиком
  (прячутся) и открываются заново той же кнопкой ⤢.
- Языки с письмом справа налево (арабский и др.) отображаются корректно (RTL).

---

## 5. Спикеры, заметки, заголовок

- **Спикеры.** Если включена диаризация (модель указана в настройках), реплики
  помечаются `Speaker N`. Кликните по метке, чтобы **переименовать** спикера (на
  всю беседу) или **переназначить** одну реплику другому спикеру.
- **✦ Конспект** — AI-саммари беседы (обзор, ключевые пункты, задачи).
- **✨ Авто-заголовок** — сгенерировать название диалога по содержанию.

---

## 6. Экспорт

Меню диалога → **Экспорт**:

- **Markdown** — текстовый транскрипт (все языки беседы).
- **PDF** — через системную печать (корректно рендерит японский/кириллицу).
- **ZIP** — транскрипт + сохранённые аудио-клипы (если включено «сохранять
  запись»).

Папку по умолчанию для экспорта можно задать в настройках.

---

## 7. Настройки (обзор)

- **Внешний вид** — тема, размер шрифта, язык интерфейса.
- **Языки по умолчанию** — какие два языка предлагать в новом диалоге.
- **ИИ-провайдер** — режимы распознавания и перевода (💻 Локально / ☁️ API),
  пути к серверам/моделям, слои на GPU, адрес и ключ API, старт серверов при
  запуске.
- **Звук** — источник (микрофон / системный звук), устройство ввода,
  длительность паузы, «сохранять запись», модель диаризации, «определять чужие
  языки».

---

## 8. Приватность и данные

- В **локальном** режиме аудио и текст **не покидают** компьютер.
- В **API-режиме** аудио/текст отправляются на выбранный сервер — не используйте
  для конфиденциальных бесед без проверки политики провайдера.
- **API-ключ** хранится в нативном хранилище секретов ОС (Windows Credential
  Manager), **не** в открытом виде.
- Исходное аудио по умолчанию **не сохраняется** — только текст (включается
  опцией «сохранять запись»).
- Где лежат данные:
  - История бесед: `%APPDATA%\ai.kaigi.desktop\kaigi.db`
  - Логи: `%LOCALAPPDATA%\ai.kaigi.desktop\logs\kaigi.log`

## 9. Решение проблем

| Симптом | Что сделать |
| --- | --- |
| SmartScreen блокирует запуск | «Подробнее» → «Выполнить в любом случае» (приложение без подписи). |
| «Подготовка сервиса…» долго висит | Локальные серверы стартуют (грузится модель). Если >2 мин — проверьте пути к серверам/моделям в настройках и `kaigi.log`. |
| Ошибка распознавания/перевода | Красная плашка покажет причину. Проверьте, что серверы/ключ настроены; для API — лимиты и доступность. |
| Реплика уехала не в ту колонку | Наведите на строку и нажмите **⇄**, выберите верный язык. |
| Окно-презентер пустое | Закройте и откройте его заново кнопкой **⤢** (окно перезапрашивает состояние). |
| Хочу начать с нуля | Закройте приложение и удалите `kaigi.db` (см. пути выше). |

---

## 10. Ограничения текущей версии

- Добавление языка переводит только **новые** реплики (история остаётся с «—»).
- Интерфейс пока полностью на русском.
- На 4–5 языках в локальном режиме растёт задержка и нагрузка на GPU (до N−1
  переводов на реплику).
- Приложение под Windows; сборки под macOS/Linux пока нет.

Нашли проблему? Приложите строку из `kaigi.log`, шаги воспроизведения и (по
возможности) скриншот — так быстрее разберёмся.
