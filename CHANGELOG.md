# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии —

попадают только релизы (см. [docs/ROADMAP.md](docs/ROADMAP.md)).

## [Unreleased]

### Добавлено
- Замер задержки по стадиям (PROJECT.md §10.16): ожидание паузы, очередь,
  сегментация, распознавание, перевод в каждый язык. Хранится у реплики,
  пишется в лог строкой `latency:`; «Настройки → Диагностика» показывает разбивку
  при наведении на время реплики и медиану / p95 по беседе.
- Бенчмарк качества и скорости на Google FLEURS (PROJECT.md §10.19):
  `node scripts/fleurs-fetch.mjs` + `cargo run --release --example bench`. Те же
  провайдеры и серверы, что в приложении; WER/CER, определение языка, chrF
  перевода, задержка последовательного и параллельного перевода. Результаты —
  `docs/BENCHMARK.md`.

### Изменено
- Перевод в N языков (PROJECT.md §10.17): оригинал реплики появляется сразу после
  распознавания, переводы догружаются по мере готовности; все целевые языки
  переводятся одновременно, а не по очереди (6 языков: 4,8 → 3,4 с по бенчмарку).
- «Отсчёт до перевода» по умолчанию 1 с вместо 3 с: ожидание после фразы 2,5 с
  вместо 4,5 с (по бенчмарку пауза составляла ~80% задержки в режиме 2 языков).
  Касается новых установок; у текущих пользователей сохранённое значение не
  меняется — его можно уменьшить в «Настройки → Звук».

### Исправлено
- Иероглифы в переводах малой моделью: Qwen2.5-3B вставлял китайский текст в
  ~25% переводов на русский. Локальный llama-server теперь получает грамматику,
  запрещающую иероглифы/кану/хангыль для языков, которые ими не пишутся (0 из 100 на
  бенчмарке); для облачных API — повтор с явной инструкцией. В промпте перевода —
  полные названия языков вместо кодов. chrF перевода на русский: +3…+10.
- Локальный whisper.cpp: разрывы строк посреди слов в распознанном тексте
  («солн / ечная»). Сервер склеивал свои сегменты через перевод строки, а граница
  сегмента может проходить внутри слова. Найдено бенчмарком.
- Зацикливание малой модели при переводе (Qwen2.5-3B → монгольский генерировал
  16 тыс. токенов) занимало слот llama-server на 90 с и тормозило остальные
  переводы. Теперь у ответа LLM есть потолок длины (`max_tokens`).
- Определение языка: whisper.cpp сообщает язык полным названием, а приложение
  знало только 15 названий — например, монгольский приходил как `mongolian` и не
  сопоставлялся с `mn`. Теперь используется полная таблица языков Whisper (~100).
- Локальный перевод быстрее и надёжнее: llama-server запускается с `--cache-ram 0`
  (кэш промптов в RAM стоил ~0,6 с, до 15 с на запрос; 6 параллельных переводов —
  медиана 2,1 с вместо 7,0 с), если сборка поддерживает флаг. Редкая ошибка
  сервера «Failed to parse input» (битый UTF-8 от модели) повторяется до 2 раз.
- Большие локальные модели не запускались: llama-server открывает порт только после
  загрузки модели, а Qwen2.5-14B (9 ГБ) грузится ~76 с при таймауте 45 с. Таймаут
  теперь 45 с + 15 с на ГБ модели (до 5 мин).
- llama-server занимал полный контекст модели (32k токенов, ~6 ГБ KV-кэша для 14B):
  whisper large-v3 + Qwen 14B забивали 15,9 из 16 ГБ VRAM. Контекст ограничен 16k.

## [0.1.4] — 2026-10-13

- Файл `LICENSE` (MIT) — лицензия теперь определяется GitHub.
- README: раздел «Установка (Windows)» с пояснением про SmartScreen и раздел

## [0.1.3] — 2026-07-10

### Добавлено
- Смена говорящего без паузы: сегментация pyannote-3.0 (ONNX) режет фрагмент речи по
  поворотам, каждая часть получает свой STT, язык, перевод и метку спикера.

### Исправлено
- Пакет исправлений, найденных при тестировании сегментации.

## [0.1.2] — 2026-07-07

### Добавлено
- Индонезийский язык.

### Исправлено
- Пресеты API-провайдеров (Groq, Gemini) теперь выставляют рабочие модели —
  раньше оставалась локальная модель, и Groq отвечал 404.

## [0.1.1] — 2026-07-02

### Исправлено
- Окно-презентер не подхватывало тему и шрифты (не подключался `global.css`).
- Атомарная запись сообщения с переводами; восстановление после паники при старте
  записи; лишние сохранения настроек в StrictMode.

### Изменено
- Большой рефакторинг без изменения поведения (Rust-ядро, React, CSS); быстрее
  контекст для перевода и трансляция в презентер.

## [0.1.0] — 2026-07-02

Первый публичный релиз.

- Захват микрофона и системного звука (WASAPI loopback) с VAD.
- Локальное распознавание (whisper.cpp) и перевод (llama.cpp) как сайдкар-серверы;
  опциональный OpenAI-совместимый API-режим, раздельно для STT и перевода.
- Режим 2 языков (две панели) и 3–5 языков (сетка колонок), язык фразы
  определяется автоматически, ручная смена языка реплики.
- Диаризация спикеров с переименованием; перенос реплики на другого спикера.
- Два окна-презентера с выбором языка, размером шрифта и темой.
- Конспект и авто-заголовок беседы, история в SQLite, экспорт Markdown / PDF / ZIP.
- Мастер первого запуска, индикатор подготовки серверов, 14 языков интерфейса.
- Портативный `KaigiAI.exe`, руководство пользователя `docs/USER-GUIDE.md`.
