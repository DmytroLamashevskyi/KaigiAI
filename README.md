# KaigiAI (会議AI)

Десктоп-приложение для **реал-тайм перевода живой речи между несколькими
языками**, работающее **полностью офлайн**. Захватывает микрофон и системный звук,
распознаёт речь и переводит между 2–5 языками прямо на вашем устройстве — аудио и
текст никуда не уходят. Опционально можно подключить облачный API-провайдер для
слабых ПК.

Стек: **Tauri v2 + Rust-ядро + React 18 / TypeScript (Vite)**. Интерфейс в стиле
Claude Desktop. Руководство пользователя — в [docs/USER-GUIDE.md](docs/USER-GUIDE.md);
подробный дизайн — в [docs/PROJECT.md](docs/PROJECT.md); чек-лист ручной проверки —
в [docs/TESTING.md](docs/TESTING.md).

## Возможности

- 🎙️ Захват микрофона + системного звука (WASAPI loopback) с VAD.
- 🗣️ **Локальное** распознавание речи (whisper.cpp) и автоопределение языка.
- 🔁 Перекрёстный перевод: 2 языка — двумя панелями параллельного транскрипта,
  **3–5 языков** — сеткой из N колонок (каждая реплика во всех языках беседы).
- 🧑‍🤝‍🧑 Диаризация спикеров (опц.) — метки `Speaker N` с персистентным
  переименованием на беседу (ONNX-эмбеддинг через `ort`).
- 📝 Заметки и AI-саммари беседы.
- 💾 История диалогов в локальном SQLite; экспорт Markdown / PDF / ZIP
  (транскрипт + аудио-клипы).
- 🌐 14 языков интерфейса.
- ☁️ Опциональный API-режим (OpenAI-совместимый: облако / Ollama / LM Studio /
  корпоративный сервер) — для машин без GPU.

🔒 **Приватность.** Ключ API хранится в нативном хранилище секретов ОС (Windows
Credential Manager), **не** в открытом виде. Исходное аудио по умолчанию не
сохраняется — только текст.

## Установка (Windows)

Скачайте `KaigiAI.exe` со страницы
[Releases](https://github.com/DmytroLamashevskyi/KaigiAI/releases) — это портативный
файл, установка не нужна. Пошаговая настройка — в [docs/USER-GUIDE.md](docs/USER-GUIDE.md).

> ⚠️ **SmartScreen.** Сборка пока **не подписана** цифровым сертификатом, поэтому при
> первом запуске Windows покажет «Windows защитил ваш компьютер / неизвестный
> издатель». Нажмите **«Подробнее» → «Выполнить в любом случае»**. Если не доверяете
> бинарнику — соберите приложение из исходников (см. ниже). Подпись релизов — в
> планах ([docs/ROADMAP.md](docs/ROADMAP.md)).

## Известные ограничения

Проект на ранней стадии (v0.1.x, один разработчик) — честный список того, что стоит
учитывать перед использованием в работе:

- **Это черновик субтитров, а не замена переводчику.** Для договоров, условий
  поставки и юридически значимых формулировок нужен человек. Малые локальные модели
  (Qwen2.5-3B) передают скорее смысл, чем точный текст.
- **Только Windows.** Протестировано на NVIDIA GPU (CUDA 12.4). CPU-сборки
  работают, но заметно медленнее. macOS (Apple Silicon) — в планах.
- **Языки.** Замерено на открытом корпусе FLEURS ([docs/BENCHMARK.md](docs/BENCHMARK.md)):
  распознавание ru / en / ja / zh / ko — 4–8% ошибок, индонезийский — 13%.
  **Монгольский не поддерживается**: Whisper medium его не распознаёт. Другие языки
  не замерялись — проверьте на своём материале.
- **Перевод на русский малой моделью.** Qwen2.5-3B в ~20% переводов на русский
  вставляет китайские иероглифы; для русского лучше модель 7B+ или API-режим.
- **Задержка растёт с числом языков.** Каждая реплика переводится во все остальные
  языки беседы, поэтому при 4–5 языках в локальном режиме растут задержка и нагрузка
  на GPU. Замеры на RTX 3080 Ti Laptop — в [docs/BENCHMARK.md](docs/BENCHMARK.md):
  обработка ~1,2 с для 2 языков и ~5 с для 7; основную часть задержки в режиме
  2 языков занимает пауза перед финализацией фразы (4,5 с по умолчанию).
- **Окна-презентеры** — до двух (проектор / второй монитор). Трансляции перевода на
  устройства участников по локальной сети пока нет — используйте демонстрацию экрана
  в созвоне.
- **API-режим отправляет данные наружу.** Аудио и текст уходят на выбранный
  сервер — для конфиденциальных встреч используйте локальный режим или свой сервер.
  Gemini через OpenAI-совместимый интерфейс умеет только перевод, не распознавание.
- **Правовые вопросы** (согласие участников на распознавание, трансграничная
  передача персональных данных в API-режиме) — на стороне пользователя. Хорошая
  практика — предупреждать участников, что встреча распознаётся и переводится.

## Быстрый старт (разработка)

Требуется Node.js 18+, Rust (stable) и MSVC build tools.

```powershell
npm install          # зависимости фронтенда
npm run dev          # Vite dev-сервер (только UI)
npm run tauri dev    # полное приложение (Rust + webview)
```

## Сборка релиза

```powershell
npm run tauri build
```

Артефакты появятся в `src-tauri/target/release/`:
- `app.exe` — портативный исполняемый файл;
- NSIS-инсталлятор и MSI — в `bundle/nsis/` и `bundle/msi/`.

## Локальные серверы и модели

Локальный режим поднимает whisper.cpp и llama.cpp как **сайдкары** (дочерние
процессы) и общается с ними по OpenAI-совместимому HTTP на `localhost` (порты 8771
для whisper, 8770 для llama, с фолбэком на свободный порт). Приложение само
запускает их перед записью, делает health-check и глушит при выходе.

Бинарники и веса **не входят в сборку** — их нужно скачать один раз и указать пути
в настройках. Ниже — протестированная конфигурация (CUDA 12.4, NVIDIA GPU).

### 1. Серверные бинарники (CUDA)

| Что | Источник |
| --- | --- |
| whisper.cpp (CUDA) | [whisper-cublas-12.4.0-bin-x64.zip](https://github.com/ggml-org/whisper.cpp/releases/download/v1.8.5/whisper-cublas-12.4.0-bin-x64.zip) (релиз `v1.8.5`) |
| llama.cpp (CUDA) | [llama-b9442-bin-win-cuda-12.4-x64.zip](https://github.com/ggml-org/llama.cpp/releases/download/b9442/llama-b9442-bin-win-cuda-12.4-x64.zip) (релиз `b9442`) |
| CUDA-рантайм для llama | [cudart-llama-bin-win-cuda-12.4-x64.zip](https://github.com/ggml-org/llama.cpp/releases/download/b9442/cudart-llama-bin-win-cuda-12.4-x64.zip) |

Распакуйте whisper-архив в отдельную папку (внутри будет `whisper-server.exe`).
llama-архив и `cudart`-архив распакуйте в **одну общую** папку (DLL из cudart
должны лежать рядом с `llama-server.exe`).

> Без GPU берите `*-bin-win-cpu-x64`-сборки с тех же релизов и поставьте «Слои на
> GPU» = 0.

### 2. Модели

| Роль | Файл | Источник |
| --- | --- | --- |
| STT (Whisper) | `ggml-medium.bin` (~1.5 ГБ) | [HuggingFace](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-medium.bin) |
| LLM (перевод) | `qwen2.5-3b-instruct-q5_k_m.gguf` (~2.3 ГБ) | [HuggingFace](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/resolve/main/qwen2.5-3b-instruct-q5_k_m.gguf) |
| Диаризация (опц.) | `wespeaker_en_voxceleb_resnet34_LM.onnx` (~25 МБ) | [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx/releases/download/speaker-recongition-models/wespeaker_en_voxceleb_resnet34_LM.onnx) |

> Для машин помощнее (16 ГБ VRAM) можно взять `large-v3` STT и Qwen2.5-7B Q5 —
> см. тиры железа в [docs/PROJECT.md](docs/PROJECT.md) §10.1.

### 3. Настройка в приложении

Откройте **Настройки → ИИ-провайдер → режим «💻 Локально»** и укажите:

- путь к `whisper-server.exe` и к модели Whisper (`.bin`);
- путь к `llama-server.exe` и к модели LLM (`.gguf`);
- **Слои на GPU** (`-ngl`): `0` — только CPU; больше нуля — выгрузка слоёв на GPU
  (на CUDA-сборке смело ставьте `99`, чтобы выгрузить всё, что влезает в VRAM);
- (опц.) путь к ONNX-модели диаризации — пустой путь выключает диаризацию.

После этого начните запись — приложение само поднимет серверы локально.

## Бенчмарк качества и скорости

Замеры распознавания (WER/CER), определения языка, качества перевода (chrF) и
задержки на открытом корпусе Google FLEURS. Результаты —
[docs/BENCHMARK.md](docs/BENCHMARK.md).

```powershell
node scripts/fleurs-fetch.mjs                     # один раз: выборка FLEURS (~200 МБ в bench/)
cd src-tauri
cargo run --release --example bench -- --limit 20 # ваши настройки из приложения
```

Другую конфигурацию можно задать через `--settings file.json` или `--set ключ=значение`
(например, `--set localLlmPath=C:/models/qwen2.5-7b.gguf`); остальные опции — в шапке
`src-tauri/examples/bench.rs`. Учтите: в API-режиме бенчмарк отправляет записи
провайдеру и расходует квоту.
